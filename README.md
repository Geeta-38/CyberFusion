# CyberFusion

AI-Powered Cybersecurity Alert Analysis Dashboard

## Features

- Alert Management
- PostgreSQL Database
- FastAPI Backend
- React Dashboard
- Gemini AI Threat Analysis
- Alert Resolution Workflow
- Risk Score Visualization

## Tech Stack

- Python
- FastAPI
- PostgreSQL
- React
- Gemini API
- Recharts

## Project Workflow

Security Alert
    ↓
PostgreSQL Database
    ↓
FastAPI Backend
    ↓
React Dashboard
    ↓
Gemini AI Analysis
    ↓
Alert Resolution

## Run Backend

cd backend
source venv/bin/activate
uvicorn main:app --reload

## Run Frontend

cd frontend
npm run dev
